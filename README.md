# בוט זמינות — מד"א ירושלים

מציג את **לוח הזמינות היומי** מתוך הגיליון המשותף
(זמינות פגיות, מצנתרי מוח, בי"ח פסיכיאטרי תורן, מנהל מרחב תורן, חוסרי זמינות נוספים).

**שתי דרכים:**

| | קובץ | דורש |
|-|------|------|
| **א. ערוץ + GitHub Actions** (חינם, מומלץ) | `daily_post.py` + `.github/` | חשבון GitHub בלבד. פוסט יומי אוטומטי לערוץ. ראו **[DEPLOY.md](DEPLOY.md)** |
| **ב. בוט אינטראקטיבי** | `bot.py` | מחשב/שרת שדולק תמיד עם גישה לטלגרם. כפתורים, `/start`, "עדכון עכשיו" |

הלוגיקה המשותפת (קריאת הגיליון + עיצוב) ב-`board.py`.

* **פתוח לכולם** — כל אחד שמריץ `/start` מתחבר, אין רשימת מורשים.
* **תמיד מעודכן** — הבוט קורא את הנתונים ישירות מהגיליון בכל בקשה
  (הגיליון מתעדכן כל יום → הבוט מציג את המצב העדכני).
* **עדכון יומי אוטומטי** — מי שמתחבר נרשם אוטומטית, ומקבל את הלוח פעם ביום
  בשעה 08:15 (שעון ישראל). אפשר לבטל בכל רגע עם כפתור.

## פקודות

| פקודה | פעולה |
|-------|-------|
| `/start` | התחברות + הרשמה לעדכון היומי + הצגת הלוח |
| `/status` | הצגת הלוח העדכני עכשיו |
| `/subscribe` | הפעלת העדכון היומי |
| `/unsubscribe` | ביטול העדכון היומי |
| `/help` | עזרה |

יש גם כפתורים קבועים: «📋 מצב נוכחי» ו-«🔔/🔕 עדכון יומי», וכפתור «🔄 רענון» מתחת לכל לוח.

## התקנה והרצה (Windows)

1. יוצרים בוט חדש: בטלגרם פותחים צ'אט עם **@BotFather** → `/newbot` → מעתיקים את הטוקן.
2. מעתיקים `.env.example` ל-`.env` וממלאים את `BOT_TOKEN`.
3. מריצים דאבל-קליק על **`run.bat`** (בפעם הראשונה הוא מתקין הכול לבד).

הרצה ידנית:

```bash
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe bot.py
```

הבוט צריך לרוץ ברציפות כדי לשלוח את העדכון היומי (להשאיר את החלון פתוח,
או להריץ כשירות / משימה מתוזמנת).

## הגדרות (`.env`)

| משתנה | ברירת מחדל | הסבר |
|-------|------------|------|
| `BOT_TOKEN` | — | חובה. הטוקן מ-@BotFather |
| `SHEET_ID` | הגיליון הקיים | מזהה הגיליון מתוך ה-URL |
| `SHEET_GID` | ריק | gid של לשונית ספציפית (אם צריך) |
| `DAILY_HOUR` / `DAILY_MINUTE` | `8` / `15` | שעת העדכון היומי |
| `TZ` | `Asia/Jerusalem` | אזור זמן |
| `CACHE_TTL_SECONDS` | `60` | כמה שניות למחזר קריאה מהגיליון |

## אם הבוט לא מתחבר (`TimedOut` / `ConnectTimeout`)

הרשת חוסמת גישה ל-`api.telegram.org` (קרה במחשב הזה — DNS עובד אבל חיבור לפורט 443 נכשל).
זה נפרד מאפליקציית טלגרם, שמשתמשת בתשתית אחרת. פתרונות:

1. **להריץ מרשת אחרת** — נקודה חמה מהנייד לרוב עובדת.
2. **פרוקסי / VPN** — מפעילים VPN, או ממלאים `PROXY_URL` ב-`.env`
   (למשל `socks5://127.0.0.1:1080`).
3. **אחסון בענן (מומלץ)** — ממילא הבוט צריך לרוץ 24/7 בשביל העדכון היומי.
   Railway / Render / Fly.io / PythonAnywhere / VPS קטן. מעלים את התיקייה,
   מגדירים את משתני ה-`.env`, ומריצים `python bot.py`.

## הערות

* הגיליון חייב להישאר משותף לקריאה ("כל מי שיש לו קישור" או "פרסום לאינטרנט"),
  אחרת הבוט לא יוכל לקרוא אותו.
* רשימת הנרשמים נשמרת מקומית ב-`subscribers.db` (SQLite).
* הבוט מזהה את כותרות הסעיפים בגיליון לפי שם קבוע; שינוי שמות הסעיפים
  ידרוש עדכון של `SECTION_HEADERS` ב-`bot.py`. שינוי התוכן/הערכים לא דורש כלום.
